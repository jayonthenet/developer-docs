The Platform Orchestrator requires network access to the API server of the Kubernetes cluster hosting the runner.

For the SaaS version of the Orchestrator, refer to the [public source IPs]({{< relref "/platform-orchestrator/docs/security/connectivity#source-ips" >}}) to configure network access.

For a [self-hosted]({{< relref "/platform-orchestrator/docs/architecture/self-hosting" >}}) Orchestrator, refer to your own networking layout.

See [runner connectivity]({{< relref "/platform-orchestrator/docs/security/connectivity" >}}) for more details.

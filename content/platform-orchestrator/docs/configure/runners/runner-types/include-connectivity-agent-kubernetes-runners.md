The Kubernetes node(s) hosting the runner require network access to the Orchestrator API.

For the SaaS version of the Orchestrator, refer to the [public endpoint IPs]({{< relref "/platform-orchestrator/docs/security/connectivity#endpoint-ips" >}}) to configure network access.

For a [self-hosted]({{< relref "/platform-orchestrator/docs/architecture/self-hosting" >}}) Orchestrator, refer to your own networking layout.

See [connectivity]({{< relref "/platform-orchestrator/docs/security/connectivity" >}}) for more details.

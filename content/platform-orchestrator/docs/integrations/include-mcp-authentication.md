Using the MCP server requires authentication via a Google account on the first connect.

The authentication does not request the user's name, email address, or other personal data, from the account. An anonymous, stable user ID is still needed to enforce per-user rate limits and prevent abuse of the backing MCP server provided by [kapa.ai](https://www.kapa.ai/). For more details, refer to the [kapa.ai product documentation](https://docs.kapa.ai/integrations/mcp/overview#authentication).
